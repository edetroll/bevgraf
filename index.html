1. Grafikus primitívek JavaScriptben1. Graphics primitives in JavaScript

Az első fejezetben a rajzolás alapműveleteit és az egér eseményeinek kezelését tekintjük át. A példák a böngésző Canvas-felületén futnak, a forráskódjuk módosítható.This chapter introduces basic drawing operations and mouse event handling. Examples run on the browser Canvas and their source code can be edited.

1.1. A rajzterület és a koordináták1.1. Canvas and coordinates

A <canvas> HTML-elem téglalap alakú rajzterületet biztosít. A program a getContext("2d") hívással kapja meg a rajzoláshoz szükséges objektumot.The <canvas> element provides a rectangular drawing area. The program obtains a drawing context with getContext("2d").

A kezdőpont a bal felső sarokban van. Az x koordináta jobbra, az y lefelé növekszik. A demók 860 × 480 koordinátájú rajzterületet használnak.The origin is the upper-left corner. The x coordinate increases to the right and y increases downwards. The demos use an 860 × 480 canvas coordinate system.

const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");

1.2. Képpont (pixel)1.2. Pixel

A raszterkép alapeleme a képpont. A Canvas API-ban egyetlen képpontot egy 1 × 1 méretű kitöltött téglalappal jeleníthetünk meg. Később a raszteres algoritmusokat is erre az alapműveletre építjük.The pixel is the basic element of a raster image. On Canvas a single pixel can be represented by a filled 1 × 1 rectangle. Later raster algorithms will use this basic operation.

function putPixel(ctx, x, y, color) {
  ctx.fillStyle = color;
  ctx.fillRect(Math.round(x), Math.round(y), 1, 1);
}
putPixel(ctx, 120, 80, "rgb(255, 0, 0)");

Két egymásba ágyazott ciklussal képpontonként összeállíthatunk egy színmintát. A demó ezt is megmutatja.Two nested loops can construct a colour pattern pixel by pixel. The demo illustrates this as well.

1.3. Szakasz1.3. Line segment

A szakaszt a két végpontja határozza meg. A natív Canvas API-ban a moveTo() és lineTo() hívásokat kell egymás után használni. A későbbi geometriai algoritmusokhoz bevezetünk egy két pontot fogadó segédfüggvényt.A line segment is defined by its two endpoints. The native Canvas API uses moveTo() followed by lineTo(). We introduce a helper accepting two points to support the geometric algorithms in later chapters.

function drawLine(ctx, p0, p1, color, width = 1) {
  ctx.beginPath();
  ctx.moveTo(p0.x, p0.y);
  ctx.lineTo(p1.x, p1.y);
  ctx.strokeStyle = color;
  ctx.lineWidth = width;
  ctx.stroke();
}
const p0 = { x: 40, y: 60 };
const p1 = { x: 320, y: 180 };
drawLine(ctx, p0, p1, "rgb(255, 255, 0)", 3);
A drawLine() a Canvas rajzolófunkcióit hívja. A DDA és a Bresenham-féle algoritmus megvalósításakor viszont magunk határozzuk meg a szakasz képpontjait.drawLine() calls the Canvas drawing API. When implementing DDA or Bresenham later, we will explicitly compute the segment pixels.

1.4. Kör, ellipszis és téglalap1.4. Circle, ellipse and rectangle

A kör középponttal és sugárral adható meg. Az ellipszisnél két féltengelyt is megadhatunk. A körvonal rajzolása és az alakzat kitöltése külön művelet; a téglalap pedig közvetlenül rajzolható vagy kitölthető.A circle is defined by its centre and radius. An ellipse may have different semi-axes. Drawing the outline and filling the shape are separate operations. A rectangle can be drawn or filled directly.

drawCircle(ctx, { x: 260, y: 180 }, 100, "rgb(0, 128, 0)", 2);
ctx.fillStyle = "rgb(0, 0, 255)";
ctx.fillRect(80, 50, 200, 120);

A drawCircle() – a drawLine()-hoz hasonlóan – saját segédfüggvény. A natív Canvas-műveleteket használja.Like drawLine(), drawCircle() is our own helper using the native Canvas API.

1.5. Színek és vonalvastagság1.5. Colours and line width

Az RGB-szín három összetevőből áll: vörös (R), zöld (G), kék (B). Mindegyik érték 0 és 255 közötti egész szám. A Canvas a színt például "rgb(255, 0, 0)" karakterláncként kapja meg. Az alfa-összetevő az átlátszatlanságot szabályozza.An RGB colour consists of red (R), green (G) and blue (B) components. Each is an integer from 0 to 255. Canvas accepts a CSS colour string such as "rgb(255, 0, 0)". The alpha component controls opacity.

ctx.strokeStyle = "rgb(255, 255, 0)";
ctx.lineWidth = 3;
ctx.strokeRect(130, 50, 300, 200);

ctx.fillStyle = "rgba(255, 0, 255, 0.6)";
ctx.fillRect(180, 100, 200, 150);

Ebben a fejezetben a színt és a vonalvastagságot közvetlenül a kódban állítjuk. Ehhez külön kezelőpanelre nincs szükség.In this chapter colours and line widths are changed directly in source code, so no separate adjustment panel is needed.

1.6. Egérkezelés1.6. Mouse handling

Az egérműveleteket események kezelik. A pointerdown jelzi a lenyomást, a pointermove a mozgást, a pointerup az elengedést. A wheel esemény a görgő használatakor keletkezik.Mouse actions are handled by events. pointerdown marks a press, pointermove a movement and pointerup a release. The wheel event occurs when using the mouse wheel.

A csatolt C#-példához hasonlóan egy sárga téglalapot mozgatunk. A lenyomáskor megvizsgáljuk, hogy a mutató az alakzaton belül van-e, majd megőrizzük a fogási pont eltolását. A görgő a téglalap méretét módosítja.As in the supplied C# program, we move a yellow rectangle. On a press we test whether the pointer is inside it and preserve the grab offset. The wheel changes the rectangle size.

canvas.addEventListener("pointerdown", onDown);
canvas.addEventListener("pointermove", onMove);
canvas.addEventListener("pointerup", onUp);
canvas.addEventListener("wheel", onWheel);
