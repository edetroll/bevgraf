A kör szimmetriája és a Midpoint-módszer alkalmazása.Circle symmetry and the Midpoint method.

3.1. Midpoint körrajzoló algoritmus3.1. Midpoint circle algorithm

Az origó középpontú, R sugarú kör egyenlete x² + y² = R². A pozitív y értékeit a y = √(R² − x²) függvény írja le, de minden képponthoz négyzetgyökvonást végezni nem célszerű. A kör szimmetriája miatt elegendő a felső félkör egyik nyolcadát kiszámítani.A circle centred at the origin with radius R satisfies x² + y² = R². Its upper half is y = √(R² − x²), but evaluating a square root per pixel is unnecessary. Symmetry means that only one octant needs to be computed.

x² + y² = R²,    F(x, y) = x² + y² − R²

Az első nyolcadban a (0, R) pontból indulunk. Egy lépés során E = (x+1, y) és SE = (x+1, y−1) közül választunk. A középpont M = (x+1, y−½). A döntési változó d = F(M). Ha d < 0, a középpont a kör belsejében van, ezért E következik; ellenkező esetben SE-t választjuk.Start at (0,R) in the first octant. At each step choose between E = (x+1,y) and SE = (x+1,y−1). Their midpoint is M = (x+1,y−½), and d = F(M). If d < 0, the midpoint is inside the circle and E is chosen; otherwise choose SE.

d = (x+1)² + (y−½)² − R²;   d < 0 ⟹ E;   d ≥ 0 ⟹ SE

A döntési változó különbsége E után 2x+3, SE után pedig 2(x−y)+5. A kezdőpontban d₀ = 5/4−R. Az egész számú számítás érdekében h = d−1/4 változót vezetünk be. Ekkor h₀ = 1−R, és a döntéshez elegendő a h < 0 feltétel.After E, the decision value changes by 2x+3; after SE, by 2(x−y)+5. The initial value is d₀ = 5/4−R. To use integer arithmetic, define h = d−1/4, so h₀ = 1−R and the decision becomes h < 0.

h₀ = 1−R;    ΔE = 2x+3;    ΔSE = 2(x−y)+5

A kapott (x,y) ponthoz a koordináták előjelváltásával és felcserélésével további hét szimmetrikus pont tartozik. A ciklus addig tart, amíg x ≤ y. A képernyőn a középpont eltolását is figyelembe kell venni.From one computed (x,y) point we obtain up to seven symmetric points by changing coordinate signs and swapping x and y. The loop continues while x ≤ y. The circle centre is added when displaying the result.
